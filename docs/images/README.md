# README images

`review-ui.jpg` and `review-ui.gif` show framewise on a demo Session of 27 wildlife photos taken at NASA's Kennedy Space Center. They are works of the US government in the public domain, from the [NASA Image and Video Library](https://images.nasa.gov), downscaled to 2400 px with their EXIF kept:

- `KSC-20190925-PH-GEB01_0001` to `_0017` (13 Frames)
- `KSC-20210111-PH-JBS01_0001` to `_0080` (14 Frames)

The Session folder shown in the header was renamed for the screenshots.
